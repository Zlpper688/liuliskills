# 胶囊层与外放接口设计

系统的输出做成"一句话 + 一排胶囊"。胶囊分两种：**动词胶囊**（点即生效）和**变量胶囊**（打开原生选择器）。总原则一句话：**胶囊不内置具体内容，把可变的量做成接口，留给用户自己定。**

## 四条核心规则

1. **不内置内容。** 胶囊上不出现替用户决定的值：不预填"45 分钟"，不预填"今晚 19:00"。具体值只来自两处——用户在选择器里自己定，或系统的安排结果本身。想要推荐，让它体现在系统已经做出的安排里，不写在胶囊表面。
2. **负担最小，允许"一点点"。** 只有两种内容可以直接出现在胶囊上：状态反馈（[完成] [未完成]）和已发现的明确问题的二元出口（如时间冲突时 [搁置] [排进下一个空闲]）。这两个词本身就是决策本身，不算预填；除此之外不给更多。
3. **少写字。** 回执一句话；胶囊标签尽量四个字以内；只在用户需要知道"发生了什么"时加一行说明（如"和 19:00 课程冲突"），不写说明文。
4. **保证自主性。** 每个变量胶囊背后必须是完整的编辑器——日期选择器、分钟输入、时间选择器、列表——胶囊是门，不是笼子。用户什么都不点 = 保持现状，永远合法，永不追问。

## 两种胶囊

| 形态 | 行为 | 样式 |
| --- | --- | --- |
| 动词胶囊 | 点击即生效，最多两个并排 | 实底 |
| 变量胶囊 | 点击打开选择器 / 编辑器 | 描边弱底 |

动词胶囊只用于三类：状态反馈（完成 / 未完成）、二元出口（搁置 / 排进下一个空闲）、撤销。

## 场景定式

| 场景 | 胶囊 | 点开后 |
| --- | --- | --- |
| 记录 | 无需展开，回执一句话即完成 | — |
| 排期（哪一天） | 变量胶囊 | 直接给日期选择器 |
| 定时（开始–结束） | 变量胶囊 | 时间选择器 |
| 时长 | 变量胶囊 | 自定义输入，以分钟为单位 |
| 完成 | 动词胶囊 [完成] [未完成] | 点即生效 |
| 发现问题（冲突 / 放不下） | 一行问题说明 + [搁置] [排进下一个空闲] | 各自直接生效 |
| 提醒 / 类别 / 对象 | 变量胶囊 | 对应的选择器或列表 |

遇到新场景，先问一句："这是决策，还是变量？"决策做成动词胶囊；变量一律做成选择器入口，绝不做成预设值。

## 语气

像有耐心的人，不做机器人：根据当前情况给多个选项，必要时一句话解释为什么；不简答、不审问、不让用户把整句话重打一遍。

## 反例（出现即返工）

- 胶囊上写"建议 45 分钟，因为最近三次……"——把预填内容和解释塞上了表面。
- 替用户猜"今天还是明天"，而不是直接给日期选择器。
- 一个问题给三个以上出口，或给一份长报告。
- 变量胶囊点开是一段要用户打字的文本框，而不是选择器。

## 视觉

柔和多色，整体安静。全圆角，触达高度 ≥ 40dp；动词胶囊实底、变量胶囊描边，一眼分清"决策"与"去填"；按压反馈全局统一；大字号下胶囊可换行。胶囊层是回执的附属行，不抢主内容。
