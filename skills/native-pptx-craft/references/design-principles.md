# 设计思想细则（native-pptx-craft）

本文档是小茂答辩/汇报 PPT 的完整设计口径。动手写任何一页前先通读一遍。

## 1. 信息密度四层结构

每个核心要点页必须同时具备四层，缺一层就算没做完：

| 层 | 作用 | 形态 |
|---|---|---|
| 小标题/主张 | 这一格在说什么 | 加粗 15–21px，一句话 |
| 论据/数据 | 为什么可信 | 具体数字（292 分钟、0.50/1.30/2.00、24 条事实）、具体行为描述 |
| 金句 | 让评委记住 | 衬线体（Noto Serif SC → SimSun），17–28px，独占一行或收尾 |
| 收束/总结 | 往下引 | 一行小字或箭头指向下一页的逻辑 |

密度底线保住之后，**排布必须疏密有度**：内容区之间留 20–40px 呼吸空隙；每页有一个视觉重心（大图/大数字/大字），其余信息围绕它分级变淡（INK → INK3 → MUTED 三档灰阶就是干这个的）。

## 2. 文字简约性

- 封面只保留：kicker（学科/场合）+ 主标题 + 一行副题 + 主视觉（如手机 mockup）。装饰性线条、多段文字、徽标阵列一律不要。
- 一页一个主诉求。想放两个论点就拆两页，或做成明显的左右分栏各自成体系。
- 长句一律拆短句；一行文字最大宽度控制在 60 个汉字以内。
- 页面元素数量直觉上限：一页最多 1 个主视觉 + 3–4 个内容组 + 1 行收束。超过就说明该拆页或该删。

## 3. 配图真实感（手机 mockup 规范）

抽象占位框一眼就是 AI 味。手机必须画全骨架：

- **机身**：圆角大矩形（rx≈24），深色填充（INK），位于屏幕外圈 8px。
- **屏幕**：内嵌圆角矩形（rx≈17），PAPER/CARD 色。
- **挖孔摄像头**：屏幕顶部中央小圆（r≈3.5），机身色。
- **侧键**：机身左右两侧的 3px 小竖条。
- **home indicator**：屏幕底部居中短横条（约 64×3.5，圆角）。
- **屏内内容 = 应用真实布局**：状态栏（时间/信号）、导航标题、真实业务卡片（带真实字段如"可提取率 64%"）、底部 tab 栏（选中态加粗+短横线）。字段名用项目真实术语，不用 Lorem 占位。
- 比例：竖版手机约 1:1.7（如 150×254）。**不要画方的"手机"**。

## 4. 动效叙事编排

动画按讲故事顺序编排，不是按绘图顺序：

- **自动级联打底**：页眉 → 主体结构 → 按阅读顺序 afterEffect 链式出现（间隔 0.15–0.3s）。
- **关键交互用 on-click**：结果揭晓（如"我希望安排成？"后的重排结果）、对比揭底（"你以为的曲线"→点击→"实际的曲线+落差"→点击→学术解释）、过程分解（插入动画：原列表→复制→插入→变黄）、并列要点逐个强调（四张能力卡逐次点击）。
- **曲线用 `entrance_wipe` direction=left** 从左往右"画出来"，不用 fade。
- **插入/复制类动画**：先放"复制虚影"组（低透明度，on-click fade），再"插入项"（on-click wipe），再"受影响集变黄"（on-click fade，色块换色）。三步各自独立顶层组，重叠组标 `data-pptx-role="decoration"`。
- 单页动画步 2–8 步为宜；全部自动 = 没有节奏，全部点击 = 演讲累死。
- 金句/收束行永远是该页最后一个动画步，淡入收尾。

## 5. 文案口径（去AI味）

- 禁词：赋能、抓手、闭环（名词用法）、极致、一站式、全方位。
- 不用三段排比堆气势；用"一个具体的人在一个具体场景下的一个具体动作"。
- 数字优先于形容词："剩余 5 小时" 胜过 "时间紧张"。
- 每页文案读出来像人说的话；写完通读一遍，念着拗口的就重写。
- 示意数据必须标注 `示意 · 非实测`（MONO 小字放角落），诚实也是设计。

## 6. 页面骨架常量（deck_kit 默认值）

- 画布 1280×720；正文上界 186（页眉之下）、下界 626（页脚之上）；左右边距 80 / 1200。
- 页眉：kicker（分区号 12px MONO）+ 大标题（32px SERIF）；页脚：左注 + 右页码（01–15）。
- 灰阶三档：INK(#1F2937) / INK3(#4B5563) / MUTED(#9CA3AF)；强调色从 AMBER/RED/BLU/YEL 里选，一页最多两个强调色。
- 分区结构示例（答辩 15 页）：01 项目背景(1–4) → 02 项目现状(5–7) → 03 创新点及待解决问题(8–13) → 04 总结及感谢(14–15)；目录页对应四个大标题。
